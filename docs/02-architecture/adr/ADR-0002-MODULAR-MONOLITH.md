# ADR-0002：platform-api 先采用模块化单体

- 状态：Accepted
- 日期：2026-07-30
- 决策者：项目/架构负责人角色

## 背景

经营指标、目标、分析、知识和决策领域仍在快速演进。过早拆成多个服务会让跨域事务、部署和契约成本先于业务收益出现。

## 决策

`platform-api` 首期作为 Python 模块化单体部署。模块拥有自己的领域模型和公开接口，禁止跨模块访问私有表。异步计算进入独立 worker；语义和数据面保持独立。

## 拆分条件

模块只有在独立扩缩容、故障隔离、合规边界、技术栈或团队所有权需求被实际数据证明时才能拆分；拆分必须有 ADR、数据迁移、契约和总拥有成本评估。

## 后果

开发、测试和本地运行更简单，但必须通过依赖规则和代码评审防止演变为无边界单体。
