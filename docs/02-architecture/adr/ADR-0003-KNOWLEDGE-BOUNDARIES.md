# ADR-0003：分离三类知识资产

- 状态：Accepted
- 日期：2026-07-30
- 决策者：产品/架构/数据负责人角色

## 背景

文档检索、结构化业务语义和决策历史具有不同的权限、生命周期、索引和审计要求。把它们统称为“知识库”容易造成模型混乱和越权。

## 决策

- 企业文档知识库：文档、版本、切片、ACL、索引、检索、引用和反馈；
- 业务知识网络：客户、产品、订单、组织、指标、事件、规则及关系；
- 决策档案：问题、证据快照、假设、方案、审批、行动和结果。

三者通过稳定 ID 和受控 API 关联。知识库检索必须在召回前执行 ACL 过滤；决策引用必须保留版本和定位信息。

## 后果

领域模型和权限更清晰，代价是需要跨域关联与一致的主体标识。禁止为减少表数量而合并三类资产。
