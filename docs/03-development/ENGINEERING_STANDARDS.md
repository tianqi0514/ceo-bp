# 工程规范

| 属性 | 值 |
|---|---|
| 文档编号 | DEV-002 |
| 版本 | 0.2.0 |
| 状态 | Baseline |
| 生效日期 | 2026-07-30 |
| 责任角色 | 架构与开发负责人 |

## 1. Python

- 目标 Python 3.12，实际版本在首个代码基线中锁定；
- 使用类型标注、严格静态检查、统一格式化和 lint；
- FastAPI 只处理传输层，领域逻辑不得写入路由函数；
- 数据访问通过仓储/工作单元，模块不得读取其他模块私有表；
- 异步函数仅用于真实异步 I/O，CPU 密集任务进入 worker；
- 依赖必须锁定并可生成 SBOM。

具体工具（包管理、lint、类型、测试）在 P1 工程脚手架 ADR 中确定，避免本备忘录提前锁死版本。

## 2. Go

- Go 版本随组件准入报告锁定；
- 保留组件必须通过 `go test`、静态分析、依赖和漏洞检查；
- 上游修改集中在适配/修复层，记录与上游差异，避免不可升级的散乱 fork；
- Context 传播取消、超时、租户和追踪信息；禁止无界 goroutine 和无界缓存。

## 3. API

- OpenAPI 3.1 是外部 API 权威契约；
- 资源使用稳定 ID，时间使用 UTC RFC 3339，金额使用十进制定点与货币码；
- 列表接口统一游标分页、过滤和排序语义；
- 写操作支持幂等键；长任务返回任务资源；
- 错误体至少含 `code`、`message`、`trace_id`、`retryable` 和可选 `details`；
- 破坏性变更采用新版本和明确弃用期，CI 执行契约差异检查；
- SDK 从契约生成，业务便利封装放在生成层之外。

## 4. 数据库与迁移

- 表有明确所有模块、主键、时间和租户字段；
- 生产迁移使用 Expand → Migrate → Contract，不在同一发布先删字段再发代码；
- 迁移不可依赖人工编辑生产数据；数据修复可重入并有对账；
- 大表变更先评估锁、时长、空间和回滚；
- 敏感数据分类、加密、保留、删除和审计规则在模型评审时确定。

## 5. 事件与任务

- 事件为已发生事实，名称用过去式，包含 schema 版本、事件 ID、主体、租户和时间；
- 生产者使用事务发件箱或等价保证；消费者以事件 ID/业务幂等键去重；
- 重试使用退避和上限，永久失败进入死信/人工处理；
- 任务保存输入/输出引用、模型和代码版本、状态、进度、错误和尝试次数。

## 6. 配置、密钥与日志

- 配置分环境但不把环境值写死在镜像；
- 密钥只通过受控密钥服务/环境注入，不入 Git、镜像、日志和异常；
- 日志结构化并包含 trace/request/job ID，不打印 Token、数据库口令、原始文档或完整提示词；
- 用户可见错误不暴露堆栈、内部地址和查询文本。

## 7. AI、检索与模型

- 提示词、Embedding、重排、预测模型和评估集均版本化；
- RAG 响应必须返回可定位引用、知识版本和权限上下文；
- 评估覆盖召回、排序、引用正确性、忠实度、越权和拒答；
- 预测使用时间顺序回测，与朴素基线比较，并报告误差和区间覆盖；
- 模型输出不得直接拼接为 SQL、权限策略或高风险指令，必须经过验证与审批。

## 8. 产品界面与交互

- 页面只展示已实现、可验证的功能和真实数据；路线图、阶段编号、架构概念、交付理念和未来能力放在受控文档，不作为产品界面内容；
- 导航项只有在目标页面可访问且具备真实功能时才出现，禁止用成排禁用入口营造功能数量；
- 每个按钮必须对应明确用户目标、实际动作和可观察结果，并覆盖执行中、成功、失败及可重试状态；
- 禁用按钮只用于短暂执行中、权限不足或当前数据状态不允许操作，必须提供原因；不得用禁用按钮表示“以后开发”；
- 链接必须打开真实资源，名称准确描述目标；不得用链接或按钮代替无操作的装饰卡片；
- 经营数字必须能追溯到数据源、口径和时间，原型值、占位值或推测值不得伪装为业务事实；
- 验收时逐项清点页面内按钮、链接、菜单和表单，验证其目的、结果、错误处理、键盘操作和权限行为。
