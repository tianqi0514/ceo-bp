# 测试策略

| 属性 | 值 |
|---|---|
| 文档编号 | TST-001 |
| 版本 | 0.1.0 |
| 状态 | Baseline |
| 生效日期 | 2026-07-30 |
| 责任角色 | 测试负责人 |

## 1. 目标

以风险为中心证明平台行为正确、权限不越界、数据与分析可重现、系统可发布和可恢复。测试报告必须区分“未执行”“阻塞”“失败”和“通过”，不得用覆盖率代替质量结论。

## 2. 测试分层

| 层级 | 目标 | 主要执行时机 |
|---|---|---|
| 静态检查 | 格式、类型、漏洞、密钥、许可证、IaC | 每次 PR |
| 单元测试 | 领域规则、边界值、错误和纯算法 | 本地/每次 PR |
| 模块/组件测试 | API + 数据库、worker、适配器行为 | 每次 PR/主干 |
| 契约测试 | OpenAPI、事件和上游兼容性 | PR、上游升级、发布 |
| 集成测试 | 真实数据库、队列、对象存储、保留组件 | 主干/候选版本 |
| E2E | 关键用户旅程和跨模块权限 | 候选版本 |
| 数据/分析验证 | 口径、对账、回测、可重现性 | 候选版本/UAT |
| 非功能测试 | 性能、容量、恢复、安全、可访问性 | 里程碑/发布前 |
| 生产验证 | 烟雾、合成监测和观察窗口 | 每次生产发布 |

## 3. 强制风险测试

### 权限与租户

每个受保护资源至少覆盖：允许访问、无角色拒绝、跨组织拒绝、跨租户拒绝、已撤权会话、批量/导出、异步结果、搜索/缓存和审计记录。

### 指标与数据

验证口径版本、单位/货币、时区、空值、迟到数据、维度汇总、计划/实际对账、来源新鲜度和查询重放。使用黄金数据集和独立计算结果比对。

### 知识库/RAG

验证格式解析、重复上传、文档版本、切片定位、ACL 继承、删除/归档、关键词/向量混合召回、引用正确性、无证据拒答、提示注入和跨权限泄露。

### 预测与场景

使用滚动/扩展窗口回测，禁止随机打乱时间序列；至少与季节朴素或业务基线比较。记录数据截止点、特征、模型、参数、随机种子、误差、区间覆盖和失败场景。

### 决策闭环

验证证据不可静默变化、审批权限和顺序、行动责任人、状态机、超时、撤回、复盘以及完整审计。

## 4. 环境与测试数据

- `local`：开发反馈；
- `ci`：隔离、短生命周期、确定性数据；
- `integration`：真实中间件和上游候选组件；
- `staging`：与生产拓扑和配置类别一致，用于系统/UAT/演练；
- `production`：仅烟雾、合成和经批准的有限验证。

测试数据优先合成。确需生产样本时必须脱敏、最小化、审批、限定保留期和访问人；严禁将真实生产数据提交到 Git。

## 5. 版本准入/准出

### 测试准入

- 需求、验收标准和追踪矩阵已基线化；
- 候选制品、配置、迁移和环境可识别且冻结；
- 测试计划、数据、账号、依赖和风险准备完成；
- 单元、静态和基础契约检查通过。

### 测试准出

- 计划内用例执行完成，阻塞有批准结论；
- Sev-1/Sev-2 为零，Sev-3 有接受人和修复版本；
- 关键旅程、权限、迁移、回滚和恢复全部通过；
- 非功能指标达到版本阈值；
- 测试报告包含失败、偏差、未覆盖风险和证据；
- 测试负责人给出明确的 Go/Conditional Go/No-Go 建议。

## 6. 缺陷等级

| 等级 | 定义 | 发布规则 |
|---|---|---|
| Sev-1 | 数据丢失/泄露、全局不可用、无恢复路径 | 立即阻断 |
| Sev-2 | 核心路径不可用、严重错误决策、关键权限缺陷 | 阻断 |
| Sev-3 | 有绕行的主要功能问题或明显非功能偏差 | 需书面接受 |
| Sev-4 | 低影响显示、易用性或文档问题 | 可计划修复 |

## 7. 记录

每个候选版本从 [`templates/TEST_PLAN.md`](../../templates/TEST_PLAN.md) 创建测试计划，从 [`templates/TEST_REPORT.md`](../../templates/TEST_REPORT.md) 创建测试报告，放入 `records/tests/<version>/`。报告引用稳定流水线、日志、截图或导出证据，并注明保留位置。
