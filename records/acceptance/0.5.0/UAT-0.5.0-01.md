# UAT-0.5.0-01：KWeaver P2 知识网络技术验收

- 候选版本：`0.5.0-rc1`
- 环境：本地隔离项目 `ceobp-kweaver-p2`，`127.0.0.1:19006`
- 执行日期：2026-08-03
- 验收性质：前后端联合技术验收，业务负责人正式 UAT 待执行
- 系统测试：[TR-0.5.0-02](../../tests/0.5.0/TR-0.5.0-02.md)
- 结论：Conditionally Accepted（仅 P2 开发基线）

## 验收前置条件

- KWeaver Core、SDK、DIP、Admin 提交均由 `upstream/kweaver.lock.yaml` 锁定；
- 所有测试数据为非敏感的经营分析示例；
- 9006 和其他 Docker 项目不在本次变更范围；
- 本次不验收生产认证、审计、性能、备份恢复和正式业务模型。

## 用户旅程验收

| 步骤 | 用户操作 | 可观察结果 | 结果 |
|---|---|---|---|
| 打开系统 | 访问知识网络工作台 | 直接进入业务知识网络任务，不展示开发状态 | Pass |
| 查询网络 | 输入名称关键字并查询 | Platform API 调用真实 BKN 返回匹配网络 | Pass |
| 创建网络 | 填写名称、说明和标签后提交 | 返回真实 Core ID，输入字段完整显示并持久化 | Pass |
| 查看详情 | 点击“查看详情” | 返回真实对象、关系、动作和分组计数 | Pass |
| 刷新恢复 | 刷新列表或 BKN 重启后再次查询 | 已创建网络仍存在，内容一致 | Pass |
| 操作约束 | 查看尚无对象类型的网络 | 不显示必然失败的全量构建按钮 | Pass |

## 技术验收

| 项目 | 验收标准 | 结果 |
|---|---|---|
| 隔离性 | 网络、卷、容器名独立；不绑定 9006 | Pass |
| 最小权限 | 业务容器非 root、只读根文件系统、drop all capabilities | Pass |
| 可重现构建 | 锁定提交、固定 Go builder digest、补丁失败即停止 | Pass |
| 数据真实性 | 无前端硬编码经营网络；API 数据来自 MariaDB/BKN | Pass |
| 错误边界 | 上游错误映射为稳定且不泄密的平台错误 | Pass |
| 自动化门禁 | 文档、Python、前端、类型、覆盖率与构建全绿 | Pass |

## 条件项

| 条件 | 影响 | 下一阶段准出标准 |
|---|---|---|
| 对象/关系/指标编辑未交付 | 尚不能形成可构建经营语义模型 | 完成首个对象类型前后端纵向切片及真实 Core 验收 |
| 开发栈关闭认证和审计 | 不满足企业生产安全要求 | 生产模板启用认证、授权、Kafka SASL 审计和密钥托管 |
| 未做恢复与容量验证 | 无生产 RTO/RPO 和容量证据 | 完成备份恢复、压力、安全与故障演练报告 |
| 未部署 9006 | 共享环境仍是历史版本 | 业务、数据、安全、运维共同签署后再制定迁移窗口 |

P2 已证明“Python 业务面 + 复用 KWeaver Go 核心服务”的路线可行，并形成真实创建、查询、详情和持久化闭环。该结论只批准继续开发，不批准替换 9006 或投入生产。
