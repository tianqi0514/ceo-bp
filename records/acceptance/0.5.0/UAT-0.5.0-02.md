- 执行日期：2026-08-03
- 验收性质：前后端联合技术验收，业务负责人正式 UAT 待执行

## 用户旅程验收

| 步骤 | 用户操作 | 可观察结果 | 结果 |
|---|---|---|---|
| 进入网络 | 选择“集团经营分析网络”并查看详情 | 显示真实模式统计和经营对象区域 | Pass |
| 查看对象 | 查看“客户”对象 | 显示 5 个真实字段及代码、主键、显示字段 | Pass |
| 打开表单 | 点击“新增对象类型” | 显示完整字段建模表单，不展示开发状态或概念卡片 | Pass |
| 维护字段 | 添加/删除字段并选择类型、主键、显示字段 | 控件均改变实际提交契约，有校验和禁用状态 | Pass |
| 创建对象 | 提交合法字段 | Vega 数据集和 BKN 对象真实创建，返回 Core ID | Pass |
| 重启恢复 | BKN 重启后重新打开详情 | 对象和字段保持一致 | Pass |
| 无效操作治理 | 查看资源直连对象 | 不显示 Core 必然拒绝的构建按钮 | Pass |

## 技术验收

| 项目 | 验收标准 | 结果 |
|---|---|---|
| 防腐层 | 前端和业务路由不依赖 KWeaver 原始字典 | Pass |
| SDK 复用 | 对象类型使用锁定官方 SDK，平台只处理契约漂移 | Pass |
| 数据边界 | 经营对象使用独立目录，不污染 BKN 内部概念目录 | Pass |
| 补偿 | BKN 拒绝时删除已建托管数据集 | Pass（自动化） |
| 输入安全 | 字段白名单、代码格式、唯一性和键成员校验 | Pass |
| 可恢复性 | BKN 重启后 MariaDB 中对象模式可回读 | Pass |
| 浏览器质量 | 无横向溢出、无控制台错误、主要操作可访问 | Pass |
| 隔离性 | 未绑定或修改 9006，未影响其他 Compose 项目 | Pass |

## 条件项

| 条件 | 影响 | 后续准出标准 |
|---|---|---|
| 未导入对象实例数据 | 尚不能查询真实客户记录 | 完成数据导入/接入、质量校验和对象查询 |
| 未交付关系与指标 | 尚不能形成经营关联和指标分析 | 完成关系类型与首个指标纵向切片 |
| 索引参数存在 SDK 缺口 | 不能安全开放关键词/全文索引配置 | 升级或修复 SDK 并增加 Core 契约回归 |
| 无可靠异步补偿 | 极端故障可能遗留托管数据集 | 增加补偿任务、审计和运维清理手册 |
| 开发栈无认证 | 不满足企业生产安全 | IAM、授权、审计和租户隔离验收通过 |

## 结论

对象类型切片已经形成“用户表单—Python 防腐层—Vega 数据集—BKN 对象—重启持久化”的真实闭环，可以继续开发对象数据、关系和指标。该结论不代表完整决策系统验收，不批准部署到 9006 或投入生产。
