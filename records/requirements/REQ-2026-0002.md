# REQ-2026-0002：经营对象类型建模纵向切片

- 状态：Conditionally Accepted
- 优先级：P0
- 责任角色/人员：产品负责人 / Codex 实施
- 目标版本：0.5.0-rc1
- 创建/更新日期：2026-08-03

## 业务问题与用户

经营分析人员需要把“客户、产品、组织、合同”等结构化经营实体定义到 KWeaver 业务知识网络中。此前系统只能创建知识网络和查看数量，无法建立对象字段、主键和显示口径，因此尚不能承载真实经营语义。

## 预期价值与衡量

| 指标 | 基准 | 目标 | 证据 |
|---|---:|---:|---|
| 可由经营用户创建的真实对象类型 | 0 | 至少 1 个 | 真实 Core API 与重启持久化测试 |
| 对象字段契约 | 无 | 字段代码、业务名称、类型、主键、显示字段完整持久化 | SDK 契约与 API 回读 |
| 无效交互 | 存在不适用于资源直连对象的构建入口 | 0 个已知无成功结果的按钮 | 浏览器交互清单 |
| 失败资源残留 | 未定义 | BKN 拒绝创建时自动清理托管 Vega 数据集 | 防腐层自动化测试 |

## 范围

- 在知识网络详情中列出真实 KWeaver 对象类型及字段；
- 创建对象类型并定义 1—50 个字段；
- 支持文本、整数、小数、日期时间和布尔字段；
- 指定单一主键和显示字段；
- 为每个对象创建独立 Vega 托管数据集，并绑定到 BKN 对象类型；
- 对 Core 稀疏创建响应执行公开 SDK 回读；
- 对创建失败执行托管数据集补偿删除；
- 通过真实 API、BKN 重启和浏览器完成验收。

## 非范围

- 导入或编辑对象实例数据；
- 对象类型修改、删除和版本发布；
- 关系类型、指标、动作和概念分组编辑；
- 资源直连对象的知识索引构建；
- 生产认证、租户权限、审计和 9006 发布。

## 验收标准

1. Given 用户打开一个知识网络，When 查看详情，Then 页面列出 Core 中真实存在的对象类型、字段、主键和显示字段；
2. Given 用户填写合法对象与字段，When 点击“创建对象类型”，Then 平台先创建独立 Vega 数据集，再通过官方 SDK 创建 BKN 对象并返回真实 ID；
3. Given 字段代码非法、重复或主键/显示字段未声明，When 提交，Then 前后端均拒绝请求且不创建对象；
4. Given BKN 拒绝对象创建，When 平台已创建托管数据集，Then 平台尝试补偿删除且向用户返回稳定错误；
5. Given BKN 服务重启，When 再次查询，Then 对象类型和字段保持一致；
6. Given Core 明确拒绝资源直连对象的全量构建，Then 页面不展示该构建按钮。

## 设计、依赖与风险

- 设计依据：[KWeaver 重构实施蓝图](../../docs/02-architecture/KWEAVER_REFACTOR_BLUEPRINT.md)；
- API：`GET/POST /api/v1/knowledge-networks/{id}/object-types`；
- 上游：锁定 KWeaver Python SDK、BKN object-types 和 Vega dataset/resource；
- 已知上游缺陷：SDK 开启关键词索引时未提供 Core 要求的 `ignore_above_len`，本切片不开放该开关；
- 数据：对象创建时只有字段模式，没有实例数据，不宣称已接入企业经营事实；
- 安全：本地 P2 栈关闭认证，仅允许 `127.0.0.1:19006`，禁止生产使用。
