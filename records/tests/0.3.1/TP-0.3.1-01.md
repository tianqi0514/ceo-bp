## 目标与范围

验证控制台只呈现当前真实可用的运行信息，不展示路线图、阶段标签、系统概念图或未实现能力。逐项确认页面中的按钮、链接和状态都有真实数据源、明确动作与可观察结果。

非范围：经营业务功能、身份与租户、知识库、指标、预测、浏览器视觉回归矩阵、并发容量和渗透测试。

## 交互验收清单

| 交互 | 用户目的 | 实际动作 | 可观察结果 |
|---|---|---|---|
| `刷新状态` | 获取最新运行数据 | 再次请求 `/api/v1/overview` | 刷新期间按钮禁用并显示执行态；成功后更新时间改变 |
| `重新检查` | 从接口错误中恢复 | 错误态再次请求总览接口 | 错误提示清除并恢复运行数据，或展示新的真实错误 |
| `API 文档` | 查看接口说明 | 新窗口打开 `/docs` | 返回真实 Swagger UI |
| 接口路径链接 | 直接检查指定端点 | 打开后端返回的 endpoint path | 返回对应 HTML、JSON 或文档页面 |

页面不得出现不可用导航、未来功能按钮或用占位数值模拟经营状态。

## 风险与方法

| 风险 | 方法 | 通过标准 |
|---|---|---|
| 概念内容被当成功能 | 组件断言与生产 JS 文案扫描 | 禁止文案不存在；无规划能力入口 |
| 按钮无行为或状态不清 | 组件交互测试与请求次数断言 | 每个按钮触发实际请求，执行态可见 |
| 链接指向虚构页面 | API 契约、组件链接和外部请求 | 链接路径来自后端注册端点且可访问 |
| 运行数据失真 | 后端时间/uptime/endpoint 测试 | 数据由运行实例计算或配置提供 |
| 升级影响共享服务 | 部署前后容器清单复核 | 只重建 CEO-BP 容器 |
