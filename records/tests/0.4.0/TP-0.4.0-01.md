## 目标与范围

验证经营用户可从首页完成一次方案比较，后端计算可复算且错误输入不会产生结果。覆盖决策标题、评价维度、权重、方向、备选方案、评分、归一化、排序、短板、敏感性、失败重试和响应式布局的代码级验证。

非范围：数据持久化、身份权限、业务指标接入、知识库、AI 自动评分、审批、行动跟踪、人工浏览器矩阵、容量和渗透测试。

## 核心用例

| 用例 | 操作 | 通过标准 |
|---|---|---|
| TC-040-01 正常分析 | 输入 2 个维度、2 个方案及完整评分 | 返回排序、首选、得分差距和明细 |
| TC-040-02 成本型维度 | 将评分方向设为“越低越好” | 后端按 `100-原始评分` 换算 |
| TC-040-03 权重归一化 | 权重合计不等于 100 | 返回归一化提示且得分可复算 |
| TC-040-04 敏感性 | 构造权重小幅变化即换首选的矩阵 | 标记敏感并指出维度 |
| TC-040-05 短板 | 高权重维度换算后低于 40 | 在对应方案列出需核查维度 |
| TC-040-06 输入校验 | 缺字段、重名、不完整或越界 | 前后端拒绝且不展示结果 |
| TC-040-07 服务失败 | 模拟 API 错误 | 保留全部输入并允许重新分析 |
| TC-040-08 动态编辑 | 添加/删除维度和方案 | 评分矩阵同步更新，保持完整契约 |
| TC-040-09 产品首页 | 打开根路径 | 进入决策任务，不展示运行状态或开发信息 |
| TC-040-10 共存部署 | 升级 9006 | 只重建 CEO-BP 容器，其他服务不变 |
